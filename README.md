# WIP Frontend - Modern Web Interface

The user interface for the WIP System, developed using **Next.js**. This application provides a seamless, reactive experience for managing complex workflows.

## 🚀 Key Features
- **Server-Side Rendering (SSR):** Optimized for speed and SEO.
- **Responsive UI:** Built with TailwindCSS for a mobile-first experience.
- **State Management:** Efficient data flow using React Hooks and Context/Zustand.
- **API Integration:** Seamless communication with the Laravel backend.

## 🛠 Tech Stack
- **Framework:** Next.js 14/15 (App Router)
- **Styling:** TailwindCSS
- **State Management:** TanStack Query (React Query) / Context API
- **Deployment:** Vercel / Nginx

## ⚙️ Installation
1. Clone the repository
2. Run `npm install` or `yarn install`
3. Configure `NEXT_PUBLIC_API_URL` in your `.env` file
4. Start development: `npm run dev`
